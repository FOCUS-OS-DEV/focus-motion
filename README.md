# Focus Motion

סקיל של Focus AI Academy שהופך את Claude Code לבמאי ולעורך וידאו. כותבים לו בעברית איזה סרטון רוצים, מאשרים תוכנית קצרה, והוא בונה את הסרטון, בודק אותו ומציג כל גרסה בדף שבו מסמנים הערות על השנייה המדויקת.

המדריך המלא בעברית, עם הפרומפטים המוכנים: https://focusai.co.il/guides/focus-motion/

## מה אפשר לעשות איתו

- סרטון שלם מרעיון, כולו אנימציה: סרטון השקה, מצגת, פתיח.
- סרטון על קריינות שהקלטתם, שבו כל מה שקורה על המסך נוחת על המילים.
- עריכה של צילומים ותמונות שלכם: תמלול, חיתוך שתיקות וטעויות, כתוביות, כותרות ואנימציות.
- עבודות קצרות: תמלול, כתוביות על סרטון קיים, ניקוי קול, סידור חומרי גלם בתיקיות.

## מה צריך

- Claude Code על המחשב, ב Windows או ב Mac.
- מודל Opus 5.5 ומעלה, עם רמת מאמץ xhigh או max.
- בפעם הראשונה Claude מתקין לבד כמה כלים חינמיים, ואתם רק מאשרים. זה לוקח כמה דקות.

## התקנה

מדביקים ב Claude Code את שתי השורות, אחת אחרי השנייה:

```
/plugin marketplace add FOCUS-OS-DEV/focus-motion
/plugin install focus-motion@focus-ai-academy
```

או בדרך הכי פשוטה: מדביקים ב Claude Code את הפרומפט הזה, ו Claude מתקין לבד:

```
תתקין לי את הסקיל Focus Motion של האקדמיה של פוקוס.
המאגר: https://github.com/FOCUS-OS-DEV/focus-motion
תבדוק אם הפקודה claude עובדת בטרמינל. אם כן, תריץ את שתי הפקודות האלה, אחת אחרי השנייה:
claude plugin marketplace add FOCUS-OS-DEV/focus-motion
claude plugin install focus-motion@focus-ai-academy
אם היא לא עובדת, תגיד לי בדיוק מה להקליד כאן בצ'אט כדי להתקין.
בסוף תגיד לי לסגור ולפתוח מחדש את קלוד קוד.
```

אחרי ההתקנה סוגרים ופותחים מחדש את Claude Code, ואז כותבים:

```
תערוך לי סרטון
```

כשיוצאת גרסה חדשה, מעדכנים בשורה אחת:

```
/plugin update focus-motion@focus-ai-academy
```

## פרומפטים מוכנים

שבעה פרומפטים להעתקה, מסרטון השקה ועד כתוביות לסרטון קיים, נמצאים במדריך: https://focusai.co.il/guides/focus-motion/

## איך זה עובד

1. עונים על כמה שאלות קצרות. לכל שאלה יש ברירת מחדל.
2. מקבלים תוכנית לסרטון ומאשרים אותה, או מבקשים שינויים.
3. רואים שניים או שלושה פריימים ראשונים ומאשרים את הכיוון.
4. הסרטון נבנה ונבדק, ונפתח בדף ההערות.
5. מסמנים הערות על רגעים מסוימים, לוחצים "סיימתי", ומקבלים גרסה מתוקנת באותו דף.

בכל שלב אפשר לוותר על מה שלא צריך, למשל כתוביות או מוזיקה, ולהמשיך ישר לעבודה.

## טוב לדעת

- הכול רץ על המחשב שלכם. ההקלטות והצילומים לא נשלחים לשום מקום, ואין שימוש בשירותים בתשלום.
- הסקיל לא מגיע עם מוזיקה. אם רוצים מוזיקה, מביאים קובץ שמותר לכם להשתמש בו.
- סרטון קצר לוקח בדרך כלל עד שעה, מהבקשה ועד הגרסה הראשונה. רוב הזמן Claude עובד לבד, ואתם נכנסים רק לאישורים.
- כל סרטון נשמר בתיקייה מסודרת משלו, והקבצים המקוריים שלכם לא משתנים.

## אחריות

השימוש בסקיל הוא באחריותכם בלבד. הוא ניתן כמו שהוא, בלי שום התחייבות, ו Focus AI Academy לא אחראית לנזק או לאובדן מכל סוג שנגרמו מהשימוש בו, כולל אובדן קבצים, תקלות במחשב וטענות של אחרים על תוכן שיצרתם.

אתם אחראים לכל סרטון שאתם יוצרים ומפרסמים, ולכך שיש לכם זכות להשתמש בכל חומר שנכנס אליו: צילומים, תמונות, מוזיקה, לוגואים וקולות, וגם הסכמה של כל מי שמופיע בו. בדקו כל סרטון, תמלול וכתוביות לפני פרסום, ושמרו גיבוי של הקבצים שלכם.

הסקיל הוא פרויקט עצמאי של Focus AI Academy, ואין לו קשר רשמי ל Anthropic.
